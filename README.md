## Selected projects

An end-to-end learning project for an AWS-based data pipeline using **Python, S3, Dagster, Terraform and GitHub Actions**. Includes Bronze/Silver/Gold data layers, data-quality checks, invalid-record quarantine, automated tests and infrastructure as code.

### [ShelfPick](https://github.com/thomasrawnson/shelfpick)
A mobile-first board game recommendation app that combines **PostgreSQL, Python/FastAPI, React and TypeScript**. It ingests collection and play-history data, supports relational modelling and migrations, and uses explainable recommendation logic to help groups choose what to play.

### [UsageGrid](https://github.com/thomasrawnson/UsageGrid)
An open-source **Swift macOS menu-bar utility** for viewing AI coding-tool usage. Focuses on local-first behaviour, clear setup and diagnostic information, and user-controlled history and notifications.
